# Photo Sheet Layout

Photo Sheet Layout — бесплатный легковесный помощник для подготовки фотографий к печати. Он предназначен для одной конкретной задачи: размещения нескольких копий фотографии на листе с последующим экспортом готового макета. В этом сценарии программа позволяет обойтись без запуска Photoshop или другого полноценного графического редактора.

Редактор работает локально в браузере: откройте файл `foto.html`, загрузите изображение и настройте лист.

## Возможности

- загрузка фотографии с компьютера, в том числе перетаскиванием в окно;
- выбор стандартного или произвольного размера фотографии;
- выбор формата и ориентации печатного листа;
- автоматическое размещение выбранного количества фотографий;
- максимальное заполнение листа и автоматический поворот фотографий;
- настройка полей и расстояния между фотографиями;
- кадрирование, масштабирование и перемещение изображения внутри кадра;
- поворот фотографии на 90 градусов;
- коррекция красного, зелёного и синего цветовых каналов;
- перемещение всей группы фотографий по листу;
- фиксация движения по одной оси при удержании `Shift`;
- привязка группы к центру листа с красными направляющими;
- отображение горизонтального и вертикального смещения от центра в миллиметрах;
- настройка линий реза и их прозрачности;
- экспорт готового листа в PNG или JPG с разрешением 300 DPI.
